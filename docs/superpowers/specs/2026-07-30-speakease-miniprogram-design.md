# SpeakEase 微信小程序初始化设计

## 目标

初始化一个使用原生 JavaScript 的微信小程序项目，为 AI 英语口语陪练产品 SpeakEase 提供可直接扩展的最小项目骨架。

## 项目结构

项目根目录包含微信小程序必需的全局文件：

- `app.js`：小程序入口，不包含业务逻辑。
- `app.json`：注册首页路由并设置基础窗口样式。
- `app.wxss`：提供最少量的全局基础样式。
- `sitemap.json`：使用默认索引规则。
- `project.config.json`：提供微信开发者工具所需的基础项目配置。

业务目录如下：

- `pages`：页面目录，首个页面为 `pages/index`。
- `components`：后续可复用组件目录。
- `services`：后续接口服务目录。
- `utils`：后续通用工具目录。
- `assets`：后续静态资源目录。
- `config`：后续项目配置目录。

除 `pages` 外，暂未使用的目录仅放置简短说明文件，避免加入无效代码。

## 首页

`pages/index` 使用微信小程序原生的 WXML、WXSS、JavaScript 和 JSON 文件。

页面内容仅包括：

1. 产品名称 `SpeakEase`
2. 副标题 `Your AI Speaking Coach`
3. 主按钮 `陪我练5分钟`
4. 次按钮 `完整模拟考试`

按钮不绑定点击事件。页面不维护状态、不发起网络请求，也不引用服务层。

## 视觉样式

首页采用单列居中布局，以浅色背景、清晰字号层级和充足留白为主。两个按钮纵向排列，使用不同视觉层级区分主次操作。样式只服务于当前静态首页，不建立复杂设计系统。

## 数据流与错误处理

当前版本没有输入、状态、接口或业务流程，因此不存在数据流和业务错误处理。后续功能应在对应页面、组件或服务中独立扩展。

## 验收标准

- 微信开发者工具能够识别并导入项目。
- 首页路由为 `pages/index/index`。
- 首页准确展示规定的四项内容。
- 两个按钮均无业务事件绑定。
- 指定目录全部存在。
- 项目保持原生微信小程序结构，不引入第三方依赖或构建工具。
